# Бот доступа

Телеграм-бот лаборатории: выдаёт доступ к серверам, заводит учётки в базе знания и доводит
заявки на доступ до того, кто за это место отвечает.

**Код живёт здесь.** До 17-10-2026 он лежал в `github.com/Vepricov/ssh_websile` вместе с
сайтом, и это стоило путаницы: на сервере было два клона, служба работала из одного, а
правки делались в другом. Теперь источник один — этот репозиторий.

## Что внутри

| файл | о чём |
|---|---|
| `server_access_bot/app.py` | разговор с человеком: анкеты, подтверждения, выдача серверов |
| `server_access_bot/gitlab_access.py` | заявки на доступ в базу знания |
| `server_access_bot/gitlab_notify.py` | что происходит с предложениями: ждёт решения, покраснело, ответили |
| `server_access_bot/mcp_*.py` | доступ к MCP и профили |
| `server_access_bot/provisioning.py` | заведение учётки на сервере |
| `deploy/` | юнит systemd и окружение |

## Выкладка

```bash
ssh do-vpn 'cd /opt/lab-access-bot && git pull --ff-only && systemctl restart server-access-bot'
```

Ключи (`ACCESS_BOT_TOKEN`, `LAB_GITLAB_TOKEN`, …) лежат в окружении службы на do-vpn и в
репозиторий не едут.

## Заявка на доступ решается в GitLab

Бот присылает заявку тому, кто за место отвечает: ведущему самой работы, затем ведущему
темы, и только если никого — владельцам лаборатории. Кнопок в сообщении нет: уровень
зависит от того, что человек будет делать, и это видно на странице состава, куда ведёт
ссылка.
