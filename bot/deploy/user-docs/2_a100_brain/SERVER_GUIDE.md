# 2 × A100 (BrainLab)

## Подключение

Персональную команду SSH, логин и пароль показывает `@brainlab_server_access_bot` в разделе «Мои серверы».

Сервер находится во внутренней сети МФТИ. Подключиться можно только из сети МФТИ или через VPN МФТИ.

На сервере установлены две NVIDIA A100 80 GB PCIe без NVLink. Перед запуском проверьте карты:

```bash
nvidia-smi
```

Выберите конкретную карту:

```bash
CUDA_DEVICE_ORDER=PCI_BUS_ID CUDA_VISIBLE_DEVICES=0 python train.py
```

Для длительной работы создайте `tmux`-сессию:

```bash
tmux new -s experiment
```

## Интернет и пакеты

У сервера нет выхода в интернет: `pip install`, `git clone` с GitHub и загрузка моделей с Hugging Face не работают. CUDA toolkit, conda и PyTorch не установлены, есть только драйвер NVIDIA и системный Python 3.12.

Готовьте окружение и модели на другой машине и копируйте их на сервер через `scp` или `rsync`. Держите архивы и окружения в `$HOME`.

## Файлы

- Личный код, окружения и результаты храните в `$HOME`.
- Перед загрузкой большого датасета проверьте свободное место через `df -h /`.
- Не записывайте большие файлы в системный `/tmp`.
- После остановки эксперимента проверьте, что процесс исчез из `nvidia-smi`.
