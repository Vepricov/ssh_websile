# Старый сервер (MIPT)

## Подключение

Персональную команду SSH, логин и пароль показывает `@brainlab_server_access_bot` в разделе «Мои серверы».

На сервере установлены A100 80 GB, A100 40 GB и RTX 2080 Ti. Перед каждым запуском проверяйте свободную память и загрузку:

```bash
nvidia-smi
nvtop
```

На этом сервере порядок CUDA-устройств без дополнительной настройки может не совпадать с индексами `nvidia-smi`. Всегда задавайте `CUDA_DEVICE_ORDER=PCI_BUS_ID`:

```bash
CUDA_DEVICE_ORDER=PCI_BUS_ID CUDA_VISIBLE_DEVICES=0 python train.py
```

Не выбирайте карту только по её номеру из старого сообщения или скрипта. Сначала проверьте текущую модель, свободную VRAM и владельцев процессов.

## Выбор GPU

- RTX 2080 Ti подходит для небольших проверок, которым хватает 11 GB.
- A100 40 GB используйте для задач, которые не требуют 80 GB.
- A100 80 GB оставляйте для больших моделей и запусков, которые не помещаются на меньшую карту.

## Файлы и процессы

- Код, окружения и результаты храните в `$HOME`.
- Перед загрузкой больших данных проверьте `df -h / /home`.
- Длительные запуски выполняйте в `tmux`.
- После остановки эксперимента проверьте, что процесс исчез из `nvidia-smi`.
