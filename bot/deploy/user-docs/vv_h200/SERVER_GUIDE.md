# H200

## VPN и подключение

Без VPN сервер недоступен по SSH.

1. Пришлите ФИО и физтеховскую почту `@undef1ne5` с просьбой оформить VPN для H200.
2. Дождитесь письма от `helpdesk02@vkusvill.ru` на физтеховскую почту.
3. После получения VPN отправьте заявку через `@brainlab_server_access_bot`.
4. Персональную команду SSH, логин и пароль смотрите в разделе «Мои серверы».

## GPU

На сервере установлены восемь NVIDIA H200. Перед запуском проверьте свободные карты:

```bash
nvidia-smi
nvtop
```

Выберите только нужные устройства:

```bash
CUDA_DEVICE_ORDER=PCI_BUS_ID CUDA_VISIBLE_DEVICES=0 python train.py
```

Не занимайте несколько H200 для задачи, которая не использует распределённое обучение.

## Файлы

- Личные окружения, код и результаты храните в `$HOME`.
- Общий каталог датасетов: `/data/datasets`.
- Верхний уровень `/data/datasets` доступен нескольким пользователям. Создавайте отдельную подпапку и не изменяйте чужие данные.
- Перед копированием большого датасета проверьте свободное место и убедитесь, что общей копии ещё нет.

Длительные расчёты запускайте в `tmux`. После завершения проверьте, что процесс освободил VRAM.
