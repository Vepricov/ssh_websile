03

GPU-сервер · защищённая сеть

H200

Нужен VPN

Восемь H200 для больших моделей и тяжёлых экспериментов. Сервер находится во внутренней сети, поэтому VPN оформляется отдельно.

Видеокарты8 × H200
ПодключениеПерсональная команда из бота
ОграничениеБез VPN SSH недоступен

Как получить доступ

  1. Пришлите ФИО и физтеховскую почту Диме @undef1ne5 с просьбой оформить VPN для H200.
  2. Дождитесь письма на физтеховскую почту от helpdesk02@vkusvill.ru.
  3. После получения VPN отправьте заявку через @brainlab_server_access_bot. Дополнительно писать администратору не нужно.

Для остальных серверов можно сразу отправлять заявку: отдельный VPN-шаг не требуется.

04

Отдельный сервис · Cloud.ru

mlsub

Очередь

Сервис запуска задач на облачных H100. Сначала получите доступ к Новому серверу (BrainLab), затем отправьте отдельную заявку на mlsub. Она требует отдельного одобрения администратора.

РесурсH100 в общей очереди
ТребованиеУже выданный BrainLab
ДоступОтдельная заявка и одобрение
mlsub run --repo https://github.com/org/repo --entry train.py --gpus 1 --dry-run
mlsub run --repo https://github.com/org/repo --entry train.py --gpus 1
mlsub list
mlsub status <job>
mlsub logs <job>
mlsub kill <job>

Что важно знать

  • Для большинства задач выбирайте 1–2 GPU: такие конфигурации очередь выдаёт быстрее.
  • Кеши и результаты храните в /home/jovyan; временная файловая система задачи очищается.
  • Если задача падает без логов, сохраняйте вывод в файл и печатайте последние строки в конце команды.
