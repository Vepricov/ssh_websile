Работа с `tmux` - Мультиплексор терминала

tmux (Terminal Multiplexer) — это мощный инструмент, который позволяет создавать и управлять несколькими терминальными сессиями в одном окне. Это особенно полезно при работе на удаленных серверах, так как позволяет сохранять запущенные процессы даже после отключения от SSH.

Основные концепции tmux:

  • Сессия (Session): Контейнер для одного или нескольких окон. Вы можете отсоединиться от сессии и присоединиться к ней позже, даже с другого компьютера.
  • Окно (Window): Виртуальный терминал внутри сессии, аналогичный вкладкам в браузере. Каждое окно может содержать несколько панелей.
  • Панель (Pane): Разделение окна на несколько областей, каждая из которых является отдельным терминалом.

Основные команды tmux:

Все команды tmux начинаются с префикса. По умолчанию это Ctrl+b. После нажатия префикса, отпустите клавиши и нажмите следующую команду.

Управление сессиями:

tmux new -s <session_name>   # Создать новую сессию с именем
tmux attach -t <session_name> # Присоединиться к существующей сессии
tmux ls                     # Показать список всех сессий
tmux kill-session -t <session_name> # Завершить сессию
Ctrl+b d                    # Отсоединиться от текущей сессии

Управление окнами:

Ctrl+b c                    # Создать новое окно
Ctrl+b n                    # Перейти к следующему окну
Ctrl+b p                    # Перейти к предыдущему окну
Ctrl+b <number>             # Перейти к окну по номеру (например, Ctrl+b 0)
Ctrl+b w                    # Показать список окон
Ctrl+b &                    # Закрыть текущее окно

Управление панелями:

Ctrl+b %                    # Разделить текущую панель вертикально
Ctrl+b "                    # Разделить текущую панель горизонтально
Ctrl+b <стрелка>            # Перемещаться между панелями (например, Ctrl+b стрелка влево)
Ctrl+b z                    # Развернуть/свернуть текущую панель на весь экран
Ctrl+b x                    # Закрыть текущую панель

Другие полезные команды:

Ctrl+b [                    # Режим копирования (для прокрутки и копирования текста)
    # В режиме копирования:
    # Прокрутка: стрелки вверх/вниз, PageUp/PageDown
    # Начать выделение: Space
    # Завершить выделение и скопировать: Enter
Ctrl+b ]                    # Вставить скопированный текст
Ctrl+b t                    # Показать часы

Использование tmux значительно повышает продуктивность при работе с удаленными серверами, позволяя эффективно управлять множеством задач и не беспокоиться о потере прогресса при разрыве соединения.
