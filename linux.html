Полезные Linux команды и утилиты

Справочник команд для эффективной работы в терминале и мониторинга ресурсов сервера

Работа в терминале Linux является неотъемлемой частью взаимодействия с SSH-сервером. Знание основных команд и утилит значительно упрощает навигацию, управление файлами, мониторинг ресурсов и выполнение различных задач. В этом разделе мы рассмотрим наиболее полезные команды, которые помогут вам эффективно работать на сервере.

1. Мониторинг системы

Эффективный мониторинг ресурсов сервера критически важен для понимания текущей нагрузки и оптимизации ваших процессов. Эти утилиты помогут вам отслеживать использование CPU, памяти, диска и GPU.

htop - Интерактивный монитор процессов

htop — это улучшенная интерактивная версия утилиты top. Она предоставляет динамический обзор запущенных процессов, позволяя легко сортировать, фильтровать и управлять ими. 

# Запуск htop
htop

Основные возможности htop:

  • Визуализация: Отображает использование CPU, памяти и swap в виде графиков
  • Сортировка: Можно сортировать процессы по CPU, памяти, PID и другим параметрам
  • Поиск: Быстрый поиск процессов по имени (клавиша /)
  • Управление процессами: Отправка сигналов (например, kill) процессам

Полезные горячие клавиши в htop:

F1 - Справка
F2 - Настройки
F3 - Поиск процесса
F4 - Фильтр
F5 - Дерево процессов
F6 - Сортировка
F9 - Убить процесс
F10 - Выход

Пробел - Отметить процесс
u - Показать процессы пользователя
t - Переключить вид дерева
H - Показать/скрыть потоки

nvtop - Мониторинг GPU

nvtop — это интерактивный монитор для NVIDIA GPU, аналогичный htop для CPU. Он предоставляет подробную информацию о загрузке GPU, использовании памяти, температуре и запущенных процессах на каждом GPU. 

# Запуск nvtop
nvtop

Основные возможности nvtop:

  • Детальная информация по GPU: Отображает загрузку каждого GPU, использование памяти, температуру и потребляемую мощность
  • Процессы на GPU: Показывает, какие процессы используют GPU и сколько ресурсов они потребляют
  • Обновление в реальном времени: Данные обновляются динамически, позволяя отслеживать изменения

nvidia-smi - Утилита командной строки для NVIDIA GPU

nvidia-smi (NVIDIA System Management Interface) — это утилита командной строки, которая предоставляет широкий спектр информации о ваших NVIDIA GPU и позволяет управлять ими.

Основные команды nvidia-smi:

# Общая информация о GPU
nvidia-smi

# Непрерывный мониторинг (обновление каждую секунду)
watch -n 1 nvidia-smi

# Информация о конкретном GPU (например, GPU 0)
nvidia-smi -i 0

# Только процессы, использующие GPU
nvidia-smi --query-compute-apps=pid,gpu_name,gpu_bus_id,used_gpu_memory --format=csv

# Подробная информация о GPU
nvidia-smi -q

# Информация о драйвере и CUDA
nvidia-smi --query-gpu=driver_version,cuda_version --format=csv

Мониторинг дискового пространства

df - Информация о файловых системах

# Показать использование дискового пространства в удобочитаемом формате
df -h

# Показать только локальные файловые системы
df -hl

# Показать информацию о конкретной директории
df -h /home

du - Размер директорий и файлов

# Показать размер текущей директории
du -sh .

# Показать размер конкретной папки
du -sh /path/to/your/folder

# Показать размер поддиректорий в текущей директории
du -h --max-depth=1 .

# Показать размер всех файлов и папок
du -ah

# Найти самые большие директории
du -h --max-depth=1 | sort -hr

2. Работа с tmux - Мультиплексор терминала

tmux (Terminal Multiplexer) — это мощный инструмент, который позволяет создавать и управлять несколькими терминальными сессиями в одном окне, отключаться от них и подключаться снова, даже если ваше SSH-соединение прервалось. Это особенно полезно для запуска длительных процессов на сервере.

Что такое tmux и зачем он нужен?

Представьте, что вы запускаете длительный скрипт на сервере, и ваше интернет-соединение прерывается. Без tmux ваш скрипт остановится. С tmux вы можете запустить скрипт в сессии tmux, отключиться от сервера, а затем снова подключиться и продолжить работу с того места, где остановились.

Основные концепции tmux:

  • Сессия (Session): Контейнер для одного или нескольких окон. Вы можете иметь несколько сессий, каждая из которых может быть названа
  • Окно (Window): Эквивалент вкладки в браузере. Каждое окно может содержать несколько панелей
  • Панель (Pane): Разделение окна на несколько независимых терминалов

Основные команды tmux:

Все команды tmux начинаются с префикса. По умолчанию префикс — Ctrl+b.

Управление сессиями:

# Запуск новой сессии
tmux new -s my_session

# Запуск новой сессии с именем
tmux new-session -d -s my_session

# Подключение к существующей сессии
tmux attach -t my_session

# Список всех сессий
tmux ls

# Завершение сессии
tmux kill-session -t my_session

# Переименование сессии
tmux rename-session -t old_name new_name

Команды внутри сессии tmux (после Ctrl+b): 

Управление сессиями:
d - Отключиться от сессии (detach)
s - Список сессий
$ - Переименовать сессию

Управление окнами:
c - Создать новое окно
n - Перейти к следующему окну
p - Перейти к предыдущему окну
[номер] - Перейти к окну с указанным номером
, - Переименовать текущее окно
& - Закрыть текущее окно

Управление панелями:
% - Разделить панель вертикально
" - Разделить панель горизонтально
стрелки - Перемещение между панелями
z - Развернуть/свернуть текущую панель
x - Закрыть текущую панель
{ - Переместить панель влево
} - Переместить панель вправо

Другие полезные команды:
? - Показать все горячие клавиши
: - Командная строка tmux
[ - Режим копирования (для прокрутки)
] - Вставить скопированный текст

Полезные конфигурации tmux

Вы можете настроить tmux под свои нужды, создав файл .tmux.conf в вашей домашней директории: 

# ~/.tmux.conf

# Изменить префикс на Ctrl+a
unbind C-b
set -g prefix C-a
bind C-a send-prefix

# Включить поддержку мыши
set -g mouse on

# Увеличить историю
set -g history-limit 10000

# Начинать нумерацию окон с 1
set -g base-index 1
set -g pane-base-index 1

# Быстрое перезагрузка конфигурации
bind r source-file ~/.tmux.conf \; display "Config reloaded!"

# Более удобные клавиши для разделения панелей
bind | split-window -h
bind - split-window -v

# Vim-подобная навигация между панелями
bind h select-pane -L
bind j select-pane -D
bind k select-pane -U
bind l select-pane -R

После сохранения файла выполните команду для применения изменений: 

tmux source-file ~/.tmux.conf

3. Файловая система: Навигация и управление

Эффективная работа с файлами и директориями — основа работы в Linux.

Навигация

# Показать текущую директорию
pwd

# Список файлов и папок
ls
ls -l          # Подробный список
ls -a          # Показать скрытые файлы
ls -lh         # Подробный список с размерами в удобочитаемом формате
ls -la         # Подробный список со скрытыми файлами
ls -lt         # Сортировка по времени изменения
ls -lS         # Сортировка по размеру

# Переход в другую директорию
cd /path/to/directory
cd ..          # На один уровень вверх
cd ~           # В домашнюю директорию
cd -           # В предыдущую директорию
cd             # В домашнюю директорию (короткая форма)

Работа с файлами и директориями

# Копирование файлов и директорий
cp file.txt new_file.txt
cp -r folder/ new_folder/    # Рекурсивное копирование директорий
cp -i file.txt backup.txt    # Интерактивное копирование (запрос подтверждения)

# Перемещение и переименование
mv old_name.txt new_name.txt
mv file.txt /path/to/another/folder/
mv *.txt text_files/         # Перемещение всех .txt файлов

# Удаление файлов и директорий
rm file.txt
rm -r directory/             # Рекурсивное удаление директории
rm -f file.txt               # Принудительное удаление без запроса
rm -rf dangerous_folder/     # Принудительное рекурсивное удаление
rm *.tmp                     # Удаление всех .tmp файлов

# Создание директорий
mkdir new_folder
mkdir -p path/to/nested/folder    # Создание вложенных директорий

# Создание пустых файлов
touch new_file.txt
touch file1.txt file2.txt file3.txt

Просмотр содержимого файлов

# Вывод всего содержимого файла
cat file.txt
cat file1.txt file2.txt      # Объединение нескольких файлов

# Постраничный просмотр
less file.txt                # Рекомендуется для больших файлов
more file.txt                # Простой постраничный просмотр

# Первые и последние строки
head file.txt                # Первые 10 строк
head -n 5 file.txt           # Первые 5 строк
tail file.txt                # Последние 10 строк
tail -n 20 file.txt          # Последние 20 строк
tail -f logfile.log          # Отслеживание изменений в реальном времени

# Подсчет строк, слов, символов
wc file.txt
wc -l file.txt               # Только количество строк
wc -w file.txt               # Только количество слов

Поиск файлов и содержимого

# Поиск файлов по имени
find . -name "*.py"
find /home/username -name "report.pdf"
find . -type f -name "*.log"        # Только файлы
find . -type d -name "backup*"      # Только директории
find . -size +100M                  # Файлы больше 100MB
find . -mtime -7                    # Файлы, измененные за последние 7 дней

# Поиск текста в файлах
grep "error" logfile.log
grep -r "function_name" .           # Рекурсивный поиск в директориях
grep -i "error" logfile.log         # Игнорировать регистр
grep -n "error" logfile.log         # Показать номера строк
grep -v "debug" logfile.log         # Исключить строки с "debug"
grep -E "error|warning" logfile.log # Поиск нескольких паттернов

# Поиск и замена в файлах
sed 's/old_text/new_text/g' file.txt
sed -i 's/old_text/new_text/g' file.txt  # Изменить файл на месте

Права доступа

# Изменение прав доступа
chmod 755 script.sh             # rwxr-xr-x
chmod 644 document.txt          # rw-r--r--
chmod +x script.sh              # Добавить право на выполнение
chmod -w file.txt               # Убрать право на запись
chmod u+x,g+r,o-w file.txt      # Комбинированные изменения

# Изменение владельца и группы
chown username:groupname file.txt
chown -R username:groupname directory/  # Рекурсивно

# Просмотр прав доступа
ls -l file.txt
stat file.txt                   # Подробная информация о файле

4. Управление процессами

# Просмотр запущенных процессов
ps aux                          # Все процессы
ps aux | grep python            # Процессы, содержащие "python"
pgrep -f "script_name"          # Найти PID процесса по имени

# Завершение процессов
kill PID                        # Мягкое завершение
kill -9 PID                     # Принудительное завершение
killall process_name            # Завершить все процессы с именем
pkill -f "script_name"          # Завершить процессы по паттерну

# Запуск процессов в фоне
command &                       # Запустить в фоне
nohup command &                 # Запустить в фоне, игнорируя SIGHUP
disown                          # Отвязать процесс от терминала

# Управление заданиями
jobs                            # Список фоновых заданий
fg %1                           # Перевести задание в передний план
bg %1                           # Перевести задание в фон
Ctrl+Z                          # Приостановить текущий процесс

5. Сетевые утилиты

# Проверка сетевого соединения
ping google.com
ping -c 4 google.com            # Отправить только 4 пакета

# Информация о сетевых соединениях
netstat -tuln                   # Прослушиваемые порты
ss -tuln                        # Современная альтернатива netstat

# Загрузка файлов
wget https://example.com/file.zip
curl -O https://example.com/file.zip
curl -L https://example.com/file.zip  # Следовать редиректам

# Передача файлов
scp file.txt user@server:/path/
rsync -avz folder/ user@server:/path/

6. Архивирование и сжатие

# Создание архивов
tar -czf archive.tar.gz folder/     # Создать сжатый архив
tar -cf archive.tar folder/         # Создать несжатый архив
zip -r archive.zip folder/          # Создать ZIP архив

# Извлечение архивов
tar -xzf archive.tar.gz             # Извлечь сжатый архив
tar -xf archive.tar                 # Извлечь несжатый архив
unzip archive.zip                   # Извлечь ZIP архив

# Просмотр содержимого архивов
tar -tzf archive.tar.gz             # Список файлов в архиве
unzip -l archive.zip                # Список файлов в ZIP

7. Полезные комбинации и трюки

# Быстрая навигация по истории команд
!!                              # Повторить последнюю команду
!n                              # Выполнить команду номер n из истории
!string                         # Выполнить последнюю команду, начинающуюся с string
Ctrl+R                          # Поиск по истории команд

# Перенаправление ввода/вывода
command > file.txt              # Перенаправить вывод в файл
command >> file.txt             # Добавить вывод в файл
command 2> error.log            # Перенаправить ошибки в файл
command &> all_output.log       # Перенаправить все в файл
command | grep pattern          # Передать вывод другой команде

# Полезные алиасы (добавить в ~/.bashrc)
alias ll='ls -alF'
alias la='ls -A'
alias l='ls -CF'
alias ..='cd ..'
alias ...='cd ../..'
alias grep='grep --color=auto'

# Мониторинг в реальном времени
watch -n 1 'df -h'              # Обновлять каждую секунду
watch -n 5 'ps aux | head -20'  # Мониторинг процессов
