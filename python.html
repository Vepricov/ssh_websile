Работа с Python и Anaconda на сервере

Полное руководство по установке и использованию Python-окружений для эффективной работы

На нашем SSH-сервере установлен базовый интерпретатор Python и пакетный менеджер pip3, которые являются общими для всех пользователей. Однако для более удобной и изолированной работы с проектами, требующими специфических версий Python или библиотек, настоятельно рекомендуется использовать Anaconda или Miniconda.

1. Почему Anaconda/Miniconda?

Anaconda и Miniconda (облегченная версия Anaconda) предоставляют мощную систему управления пакетами и окружениями. Это позволяет:

  • Изолировать проекты: Каждый проект может иметь свое собственное окружение с уникальными версиями Python и библиотек, что предотвращает конфликты зависимостей.
  • Легко управлять пакетами: conda (пакетный менеджер Anaconda) упрощает установку, обновление и удаление пакетов, включая те, которые имеют сложные зависимости.
  • Воспроизводимость: Вы можете легко поделиться своим окружением с другими, обеспечивая воспроизводимость результатов.

Рекомендация: Для большинства задач машинного обучения и научных вычислений рекомендуется использовать Miniconda, так как он занимает меньше места и позволяет устанавливать только необходимые пакеты.

2. Установка Anaconda/Miniconda на сервере

Поскольку Anaconda и Miniconda устанавливаются локально для каждого пользователя, вы можете установить их в свою домашнюю директорию на сервере. Следуйте официальному руководству по установке для Linux, но помните, что вам нужно будет скачать установочный файл на сервер.

Шаг 1: Загрузка установочного файла

Найдите актуальную ссылку для загрузки Anaconda или Miniconda для Linux на официальном сайте. Затем используйте wget или curl для загрузки файла на сервер: 

# Для Anaconda (полная версия)
wget https://repo.anaconda.com/archive/Anaconda3-2024.02-1-Linux-x86_64.sh

# Для Miniconda (рекомендуется)
wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh

Важно: Убедитесь, что вы используете актуальную ссылку на последнюю версию. Ссылки могут изменяться со временем.

Шаг 2: Запуск установочного скрипта

После загрузки запустите установочный скрипт. Следуйте инструкциям на экране. Рекомендуется установить Anaconda/Miniconda в вашу домашнюю директорию (например, ~/anaconda3 или ~/miniconda3). 

# Для Anaconda
bash Anaconda3-2024.02-1-Linux-x86_64.sh

# Для Miniconda
bash Miniconda3-latest-Linux-x86_64.sh

Важные моменты при установке:

  • Согласитесь с лицензионным соглашением (введите yes)
  • Выберите путь установки (по умолчанию ~/miniconda3 или ~/anaconda3)
  • Согласитесь на инициализацию conda (введите yes)

Шаг 3: Активация установки

После завершения установки, вам потребуется перезапустить терминал или выполнить команду для применения изменений: 

# Применить изменения к текущей сессии
source ~/.bashrc

# Или для zsh
source ~/.zshrc

3. Управление окружениями Conda

После установки Conda вы можете начать создавать и управлять виртуальными окружениями.

Создание нового окружения:

# Создать окружение с Python 3.9
conda create --name myenv python=3.9

# Создать окружение с конкретными пакетами
conda create --name ml_env python=3.9 numpy pandas matplotlib

# Создать окружение из файла
conda env create -f environment.yml

Активация и деактивация окружения:

# Активировать окружение
conda activate myenv

# Деактивировать окружение
conda deactivate

# Вернуться к базовому окружению
conda activate base

Управление окружениями:

# Просмотр списка окружений
conda env list
# или
conda info --envs

# Удаление окружения
conda remove --name myenv --all

# Клонирование окружения
conda create --name new_env --clone existing_env

4. Управление пакетами с Conda и Pip

Внутри активированного Conda-окружения вы можете использовать как conda, так и pip для установки пакетов.

Установка пакетов с Conda:

# Установка одного пакета
conda install numpy

# Установка нескольких пакетов
conda install numpy pandas matplotlib

# Установка с указанием версии
conda install python=3.9 numpy=1.21

# Установка из конкретного канала
conda install -c conda-forge scikit-learn

# Поиск пакетов
conda search tensorflow

Установка пакетов с Pip (внутри Conda-окружения):

# Установка пакета
pip install tensorflow

# Установка с указанием версии
pip install torch==1.12.0

# Установка из requirements.txt
pip install -r requirements.txt

# Установка в режиме разработки
pip install -e .

Рекомендация: Старайтесь использовать conda install для пакетов, доступных через Conda, так как conda лучше управляет зависимостями. Используйте pip install для пакетов, которые недоступны в репозиториях Conda.

Экспорт и импорт окружений:

# Экспорт окружения в файл
conda env export > environment.yml

# Экспорт только явно установленных пакетов
conda env export --from-history > environment.yml

# Создание requirements.txt для pip
pip freeze > requirements.txt

# Создание окружения из файла
conda env create -f environment.yml

5. Запуск Jupyter Notebook на сервере

Jupyter Notebook — отличный инструмент для интерактивной работы с кодом. Вы можете запустить его на сервере и получить доступ через ваш локальный браузер.

Шаг 1: Установка Jupyter (если не установлен):

# Установка через conda
conda install jupyter

# Или через pip
pip install jupyter

# Установка JupyterLab (современная версия)
conda install jupyterlab

Шаг 2: Запуск Jupyter Notebook:

# Запуск Jupyter Notebook
jupyter notebook --no-browser --port=8888

# Запуск JupyterLab
jupyter lab --no-browser --port=8888

# Запуск на конкретном IP (для доступа извне)
jupyter notebook --no-browser --port=8888 --ip=0.0.0.0

Эта команда запустит Jupyter Notebook на порту 8888 (вы можете выбрать любой свободный порт). Она выведет в терминал URL с токеном, который вам понадобится для доступа.

Шаг 3: Доступ к Jupyter через SSH-туннель:

На вашем локальном компьютере откройте новый терминал и создайте SSH-туннель: 

# Создание SSH-туннеля
ssh -N -f -L 8888:localhost:8888 username@proxy2.cod.phystech.edu -p [10096 или 10210]

# Или если у вас настроен SSH config
ssh -N -f -L 8888:localhost:8888 opt

Параметры SSH-туннеля:

  • -N: Не выполнять удаленные команды
  • -f: Перейти в фоновый режим после аутентификации
  • -L 8888:localhost:8888: Перенаправить локальный порт 8888 на порт 8888 на сервере

Теперь вы можете открыть ваш локальный браузер и перейти по адресу http://localhost:8888. Введите токен, который был выведен при запуске Jupyter Notebook на сервере.

Настройка Jupyter для удобства:

# Генерация конфигурационного файла
jupyter notebook --generate-config

# Установка пароля (вместо токена)
jupyter notebook password

6. Работа с GPU в Python

При работе с GPU-ускоренными библиотеками важно правильно настроить окружение:

Установка CUDA-совместимых пакетов:

# PyTorch с CUDA поддержкой
conda install pytorch torchvision torchaudio pytorch-cuda=11.8 -c pytorch -c nvidia

# TensorFlow с GPU поддержкой
pip install tensorflow[and-cuda]

# Проверка доступности GPU
python -c "import torch; print(torch.cuda.is_available())"
python -c "import tensorflow as tf; print(tf.config.list_physical_devices('GPU'))"

Использование GPU в коде:

# PyTorch
import torch
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
print(f'Using device: {device}')

# TensorFlow
import tensorflow as tf
gpus = tf.config.experimental.list_physical_devices('GPU')
if gpus:
    print(f'GPU available: {len(gpus)} device(s)')
else:
    print('No GPU available')

Помните: Всегда используйте CUDA_VISIBLE_DEVICES для указания конкретного GPU перед запуском ваших скриптов!

7. Best Practices для Python на сервере

Управление окружениями:

  • Используйте виртуальные окружения: Всегда работайте в активированном Conda-окружении
  • Именуйте окружения осмысленно: Используйте названия, отражающие назначение проекта
  • Документируйте зависимости: Регулярно обновляйте environment.yml или requirements.txt

Оптимизация ресурсов:

  • Мониторинг ресурсов: Используйте htop, nvtop для отслеживания потребления
  • Правильное использование GPU: Всегда указывайте CUDA_VISIBLE_DEVICES
  • Очистка кэша: Регулярно очищайте pip и conda кэш 
# Очистка conda кэша
conda clean --all

# Очистка pip кэша
pip cache purge

Безопасность и стабильность:

  • Регулярные бэкапы: Сохраняйте важные данные и конфигурации
  • Тестирование окружений: Проверяйте работоспособность после обновлений
  • Изоляция проектов: Не смешивайте зависимости разных проектов
